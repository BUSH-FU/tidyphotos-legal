# Tidyphotos — Public Web (Privacy Policy &amp; Terms)

Public marketing / legal site for **Tidyphotos**, hosted on GitHub Pages.

This repository is intentionally public. It hosts:

- The **Privacy Policy** required by the App Store.
- The **Terms of Service / End-User License Agreement**.
- App Store marketing screenshots for iPhone and iPad.

The app itself is 100% on-device, has no servers, no accounts, and no data collection. See `privacy.html` for the full statement.

## Layout

| Path | Purpose |
|---|---|
| `index.html` | Landing page with product overview, trust badges, and a screenshot gallery |
| `privacy.html` | Privacy Policy (English) |
| `terms.html` | Terms of Service / EULA (English) |
| `styles.css` | Shared stylesheet |
| `apple-store/iphone/` | iPhone App Store screenshots |
| `apple-store/ipad/` | iPad App Store screenshots |

## URL after GitHub Pages is enabled

`https://bosh-fu.github.io/tidyphotos-legal/`

Direct links used in App Store Connect:

- Privacy Policy URL: `https://bosh-fu.github.io/tidyphotos-legal/privacy.html`
- Terms of Service URL: `https://bosh-fu.github.io/tidyphotos-legal/terms.html`

## Placeholders to replace before final publishing

- `privacy@tidyphotos.app` — replace with the real support email you want exposed in App Store Connect.
- &ldquo;Tidyphotos&rdquo; — replace with your legal entity name (or keep as the personal developer name registered with Apple).
- The site is currently English-only. Add localized HTML pages (`de.html`, `fr.html`, etc.) before launching in those markets.
